Setup guide · Windows

Error Logger

After every mock, one click pulls out every question you got wrong or skipped, sorts them by subject, topic and type of mistake, and turns them into flashcards that come back exactly when you're about to forget them.

Everything runs on your own PC. No subscription, no account needed for the offline mode.

Install it

Takes 5–15 minutes, almost all of it downloading. No admin password, nothing installed system-wide.

  1. Unzip the whole folder first.

    Don't run anything from inside the zip — Windows will block it in confusing ways.

  2. Double-click Install.bat.

  3. If a blue box says “Windows protected your PC”, click More info → Run anyway.

    It says that about every unsigned script, not just this one.

  4. Answer the two questions it asks.

    Which AI model (see below), and whether to start automatically with Windows. Pressing Enter picks the recommended option both times.

  5. Wait while it downloads.

    It installs Ollama, sets up the model, copies the app, makes your shortcuts, and starts the server.

  6. Chrome opens on its extensions page. Four clicks:

    1. Turn on Developer mode — toggle, top right
    2. Click Load unpacked
    3. Press Ctrl+V — the folder path is already on your clipboard — then Enter
    4. Click Select Folder, then pin the extension from the puzzle icon

    This is the only manual step. Chrome refuses to let a script install an extension for you, for good reasons.

If anything goes wrong

Re-run Install.bat. It's safe to run any number of times, repairs a broken install, and never touches flashcards you've already saved.

Which model?

You're asked this once, during install. Both work; you can switch later.

Recommended · default

Ollama Cloud

DeepSeek V3.1, a 671-billion-parameter model, free on Ollama's preview tier.

  • Nothing to download
  • Clearly the best categorisation
  • One free sign-in during install, ~30 seconds
  • Needs internet when you capture
  • Question text goes to Ollama's servers
Private · offline

Fully local

Downloads qwen2.5:7b-instruct (~4.7 GB) and runs it on your own machine.

  • Works offline forever
  • No account, no rate limits
  • Nothing ever leaves your PC
  • Slightly rougher on subtle categorisation
  • Wants a decent machine; a GPU helps a lot

Using it every day

  1. Leave the server running.

    It's a small black console window. If it's closed, open the Testbook Error Logger shortcut on your Desktop.

  2. Give your mock as usual, then open the solution / analysis page.

  3. Click the floating Log Mistakes button, bottom right → Scan page for wrong answers.

    A few seconds per question while the AI reads them. For a single question, use Log current question only.

  4. Open localhost:8787 → Review → do your flashcards.

On Oliveboard

The extension clicks through each wrong and unattempted question itself — that site only decodes one question at a time. A toast counts the progress. Let it finish; it returns you to where you started.

Your data

Everything you've ever logged lives in one file:

C:\Users\<you>\AppData\Local\TestbookErrorLogger\errors.db

Copy it somewhere safe now and then — that single file is your revision history. Re-installing never touches it. Moving to a new PC? Install there, then drop this file in the same place.

Switching the model later

Open this file in Notepad:

C:\Users\<you>\AppData\Local\TestbookErrorLogger\Start Error Logger.cmd

Change the OLLAMA_MODEL line to one of:

ModelWhat it is
deepseek-v3.1:671b-cloudCloud, best quality (default)
gpt-oss:20b-cloudCloud, lighter and faster
qwen2.5:7b-instructFully local, offline

Save, then close and reopen the server window. Going local for the first time? Run ollama pull qwen2.5:7b-instruct once in a terminal first.

When something breaks

“Server offline” toast in Chrome
The console window is closed. Open the Desktop shortcut.
Nothing happens on the solutions page
The extension isn't loaded or is switched off. Check chrome://extensions — it should be listed and enabled. If it's missing, redo step 6 of the install.
“Auth error 401 / 403”
Your cloud sign-in expired. Press Win+R, type cmd, then run ollama signin.
“Rate limit (429)”
You hit the free cloud tier's ceiling. Wait an hour, or switch to the local model above.
“Found 0 questions”
The site changed its page layout. Try Log current question only — it grabs whatever is on screen.
Port 8787 already in use
Something else took the port. Close it, or ask whoever sent you this to change it.
A card is categorised wrongly
Happens occasionally, mostly on local mode and image-heavy quant questions. Edit the card from the dashboard.
Anything else
Re-run Install.bat.

Removing it

Run Uninstall.bat from the setup folder. It asks before deleting your flashcards.

Two things it deliberately leaves behind, in case you use them for something else: Ollama and its models (remove from Settings → Apps) and the Chrome extension (remove from chrome://extensions).
